---

Timekeepers.jl reads magnetotelluric and geomagnetic recordings (LEMI-424, GEOMAG-02, Metronix ADU), lets you mark bad intervals, writes clean data back in the same format, and estimates transfer functions. It is part of the JuliaGeophysics ecosystem.

bash
git clone https://github.com/JuliaGeophysics/Timekeepers.jl
cd Timekeepers.jl
julia --project=. -e "using Pkg; Pkg.instantiate()"

New to Julia? Getting Started goes through each step, from installing Julia to the first window.

To cite Timekeepers.jl, cite the repository: https://github.com/JuliaGeophysics/Timekeepers.jl.
